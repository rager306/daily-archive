## Reviewed-status meaning

`reviewed` in M072 means the agent inspected canonical metadata titles and curated metadata labels. It does **not** mean human-reviewed full-paper labels.

## Limitations

- Labels are title-metadata-derived.
- No PDF body text or parser-derived evidence paths yet.
- No n-ary/hyperedge scoring yet.
- No LLM judge metrics yet.
- Baseline predictions are deterministic fixtures, not model outputs.

## Next gate before DSPy/MiniMax

Before running DSPy or MiniMax:

1. Add full-paper evidence paths from parser artifacts.
2. Add per-type F1 breakdown and minimum thresholds.
3. Add n-ary/hyperedge examples.
4. Run a small baseline MiniMax extraction only after explicit authorization.
5. Keep graph writes and promotion disabled until a separate milestone authorizes them.

## Verdict

M072 satisfies the reviewed train/validation fixture expansion. It is ready for a future baseline extraction spike, but not yet for optimizer-driven DSPy/MiniMax work.
